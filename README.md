# Buy Prompts Now — GitHub Pages Storefront

Live domain: https://buypromptsnow.com/

## Upload to GitHub
1. Unzip the website archive.
2. Upload **the files inside** the extracted folder into the root of your existing GitHub Pages repository, replacing old website files. Keep `index.html`, `css/`, `js/`, `assets/`, `CNAME`, and `.nojekyll` at their supplied paths.
3. Commit the changes to your publishing branch (`main` if that is your Pages source).
4. Wait for the Pages deployment and refresh the site (Cmd+Shift+R on Mac).

Your existing Namecheap DNS records do not need changing. `CNAME` preserves your GitHub Pages custom domain. **Do not publish the paid product ZIPs on GitHub**; Payhip should host them privately.
